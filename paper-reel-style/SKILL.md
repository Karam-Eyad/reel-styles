# ورق المربعات: مونتاج تعليمي بشرائح ورق

**ستايل تاني فوق نفس المحرّك**، مش نسخة منفصلة:
- **المحرّك والأدوات والخطوات والقواعد كلها من `split-reel-style`.** اقرا `~/.claude/skills/split-reel-style/SKILL.md` كامل: الهوية، الملحقات، الموسيقى، الكابشن، الصوت، التصدير، والتحقق قبل التسليم. كلها بتنطبق هون.
- هالسكيل بيضيف `kit/paper-style.js` (لقطات ورسومات وانتقالات الورق) و`references/style-dna.md` (البصمة المقاسة، **اقراها قبل التصميم**).

```
SRS=~/.claude/skills/split-reel-style
PRS=~/.claude/skills/paper-reel-style
python $SRS/scripts/new_project.py <work> --src <الفيديو> --style paper     # بيحمّل paper-style.js تلقائياً
```
بعدها نفس الخطوات: `prepare` ← `transcribe` ← `captions` ← جدول الملحقات ← `person_matte` (للتقسيمة) ← التصميم ← معاينة ← صوت ← `render` ← `sfx` ← `export`.

## ⛔ قواعد الستايل
1. **ما في أي نص فوق الوجه** (الدعوات والأرقام فوق الراس أو بمكان الكابشن).
2. **لما يحكي عن شي، بيطلعله مثال حيّ بيتحرك**، مش صورة ثابتة. لقطة الشاشة المايلة (`SK.tilt`) بس لشي موجود فعلاً (موقعه، قناته، كورسه).
3. **ما في فقاعة وجه صغيرة بزاوية الشاشة (PiP).** جرّبناها ورفضها المستخدم.
4. **مزيج بدون التزام بشكل واحد:** بعض اللقطات رسمة لحالها، وبعضها وجهه كامل، وبعضها **تقسيمة على الورق**. الهدف إن وجهه يبيّن **55–65%** من الفيديو (وجه كامل + كرت + تقسيمة)، والباقي رسومات صافية للحظات اللي الرسمة هي الأهم. الأمثلة الصغيرة (شات، بحث، فقاعة كلام) ← تقسيمة؛ والموشن الكبير والعناوين الرئيسية ← رسمة لحالها.
5. **آخر لقطة (الفولو):** `{kind:'face', still:true}` (وجهه كامل بدون قص ولا زوم) وكرت `SK.follow` فوق راسه.

## التصميم (`shots.js`)

| اللقطة | كيف | إمتى |
|---|---|---|
| وجه كامل | `{kind:'face', zoom:1.12}` | الهوك والربط والدعوة بالآخر. الكابشن أصفر بإطار أسود (الهوية) |
| **ورق** | `{kind:'full', bg:'paper', grid:true, nocap:true}` + `SK.headline` / `SK.orbit` / `SK.tilt` | فكرة بتنكتب: عنوان، مفهوم، مثال |
| **شريحة ملوّنة** | `{kind:'full', bg:'green', nocap:true}` + `SK.slideText` | جملة قوية وحدة، ثانية أو ثانيتين |
| **كرت الوجه** | `{kind:'card', bg:'cream', logos:['a','b'], zoom, fy, capY:1250, maxWords:3}` | يحكي عن أدوات أو يسأل الجمهور سؤال |
| **تقسيمة على الورق** | `{kind:'split', bg:'paper', grid:true}` | مثال صغير حي (شات، بحث) فوق، ووجهه تحت بكرت وراسه طالع |

لقطات `split` بتحتاج `person_matte.py`، والرسمة فوقها لازم تخلص قبل y≈820 (الشات `y:180,h:620`، البحث `y:300`، العنوان `y:260`). `nocap:true` على لقطات الورق والشرائح لأن الكلام مكتوب بالرسمة.

### رسومات `paper-style.js`
- `SK.headline(t,{at, l1, l2, at2, y, size})`: عنوان بلونين (التمييز ثم الحبر)، وزاوية L بتنرسم
- `SK.orbit(t,{at, cx, cy, img, size, disc})`: صورة أو شعار فوق قرص، ودوايرين بتنرسم وعليهم نقاط بتلف
- `SK.tilt(t,{at, img, cx, cy, w, h, angle, scroll, dur})`: لقطة شاشة مايلة 3D بتنزل لتحت
- `SK.slideText(t,{at, l1, l2, color, color2, stroke})`: نص بينزلق من الجنب بضبابية حركة (`stroke` لما فوق فيديو)
- `SK.chevrons(t,{at, y, color})`: أسهم ⌄⌄⌄ بتنبض لتحت (دعوة «علّق / الرابط تحت»)
- `SK.dotDrop(t,{at, x, y})`: نقطة بتنزل وبترتد · `SK.cloud(x,y,s)`: غيمة زينة
- وكل رسومات `split-reel-style` شغّالة كمان: `SK.search` · `SK.chat` · `SK.follow` · `SK.terminal` · `SK.bigGrad`…

### الانتقالات (`tr:`)
| tr | شكله | الصوت |
|---|---|---|
| `blob` | اللقطة القديمة بتنحصر ببقعة حافتها متموّجة وحواليها حلقة بلون التمييز وبتصغر لنقطة (0.55 ث) | ووش نازل + طقّة |
| `leak` | قطع + تسريب ضوء دافي برتقالي/وردي بيمسح الشاشة (0.4 ث) | ووش لامع |
| `whip` · `zoom` · `card` · `flash` · `glitch` · `cut` | من `split-reel-style` | نفس أصواتها |

`blob` من الوجه للورق، و`leak` بين لقطات الشاشة أو للدخول على كرت الوجه، و`whip` على الشرائح الملوّنة. ما بيتكرر نفس الانتقال مرتين ورا بعض.

## ✅ قبل التسليم (إضافة على قائمة split-reel-style)
1. نقاط الشبكة باينة على الورق، وما في كلمة إنجليزية ملزوقة بعربي («بالـ AI» بمسافة).
2. لقطات الورق والشرائح `nocap:true` (ما في نص مكرر).
3. كرت الوجه: الكابشن بين الكرت والشعارات، والوجه بنص الكرت (`fy`، `zoom`).
4. وجهه بيبيّن 55–65% من الفيديو.
