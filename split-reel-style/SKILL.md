# سبليت ريل: مونتاج ريل تقني بالعربي

سكيل **مستقل**: ما بيحتاج أي سكيل تاني. بياخد فيديو كلام للكاميرا وبيطلّع ريل جاهز 9:16 فيه كابشن عربي متزامن، وموشن بيتحرك على كلامك، وانتقالات بأصواتها، ومعايرة صوت لإنستغرام.

```
SRS=~/.claude/skills/split-reel-style      # هالسكيل (المحرّك + الأدوات + الستايل)
```
ويندوز: `python` وماك/لينكس: `python3`. المسارات بالأمثلة بـ`/` وبتشتغل على الكل.

**محتويات السكيل:**
- `engine/`: محرّك الرسم (`render.js` + صفحة المحرّك + خط Rubik محلي بدون إنترنت)
- `scripts/`: `setup_check` · `new_project` · `prepare` · `transcribe` · `captions` · `person_matte` · `sfx` · `trans_sfx` · `music` · `export` · `srt` · `contact_sheet` · `snap.js`
- `kit/split-style.js`: التقسيمة، والكابشن، والانتقالات، ومكتبة الرسومات
- `references/style-dna.md`: بصمة الستايل المقاسة. **اقراها قبل تصمم اللقطات.**
- `references/brand.example.json`: قالب الهوية البصرية

ستايل ثاني فوق نفس المحرّك: `paper-reel-style` (ورق المربعات). نفس الخطوات تحت، بس بيعتمد على هالسكيل.

## ⛔ قواعد ثابتة

1. **ما في أي نص فوق الوجه.** بلقطات الوجه الكامل الوجه بيقعد تقريباً بين y 550 و1300، فأي نص إضافي (دعوة، رقم، كلمة كبيرة) بيروح **فوق الراس بمنطقة السقف (y 200–450)** أو بمكان الكابشن تحت، وبحجم معقول (≤ 84px). افحص كل لقطة وجه فيها نص بورقة المعاينة.
2. **لما يحكي عن شي، بيطلعله مثال حيّ بيتحرك، مش صورة ثابتة.** «موشن/أنيميشن» ← موشن فعلي؛ «بوصفله وبيعمل» ← `SK.chat`؛ «جملة/أمر» ← `SK.terminal` بينكتب؛ «بحثت» ← `SK.search`؛ «تثبيت» ← تيرمنال تثبيت. لقطة الشاشة الثابتة بس لما يحكي عن **شي موجود فعلاً** (موقعه، قناته).
3. **أرقام غربية (0-9)** دايماً. **عربي مع إنجليزي بمسافة**: «بالـ AI» مش «بالـAI» (غير هيك الترتيب بينقلب على الشاشة).
4. **صفر تعديل لوني على صورة المستخدم.** الألوان للكروت والنصوص بس.
5. **صورة المستخدم الشخصية كما هي**، بدون قص أو تعديل. الدايرة بتخفي الزوايا بس.
6. **ما تنشر ولا تجدول.** التسليم ملف بس، وقلّه إنك ما نشرت شي.
7. **ما تحرق أغنية محمية بالفيديو أبداً.** الترند بيضيفه هو من التطبيق وقت النشر.

### 3) التفريغ والكابشن
```bash
python $SRS/scripts/transcribe.py <work> --model medium [--prompt "جملة بتشبه كلامه، فيها الأسماء والمصطلحات"]
```
- بيطبع السكريبت مرقّماً جملة جملة. **اطبعه كامل بالشات** وقل: «شو بدك أشيل؟» (جملة معادة = الأولى هي الغلط). الحذف بـ`prepare.py --drop` وإعادة التفريغ.
- **whisper بيغلط بالعامية** (متوقع). صحّح النص بنفسك واسأله عن الكلمات اللي مش متأكد منها. `--prompt` بيحسّن الأسماء، بس قارن مع النطق لأنه بيميل للبرومبت.
- **whisper أحياناً بيسقط مقاطع كاملة:** الأداة بتكشفها وبتعيد تفريغها لحالها وبتقلّك. وإذا طلعت كلمة مدتها أكتر من 3 ثواني، راجع المقطع بالسمع.
- اكتب `<work>/fixes.json`:
```json
{ "fix": [ ["كلمات","الجملة","0"], "جملة 1 كنص كامل لو whisper هلوس", null ],
  "fx":  { "ببلاش":"kash", "كلود":"acc", "حدود":"box" } }
```
  عدد كلمات كل جملة لازم = عدد كلمات whisper لنفس الجملة (`""` مكان كلمة = تنشال). `fx` مفتاحه **كلمة وحدة**: `kash` كشيدة · `acc` لون التمييز · `box` مستطيل معكوس. بالجملة مؤثر واحد من كل نوع بالأكتر. حط فواصل (،) و(.) وين بتخلص الجمل، لأنها بتساعد بتقسيم الكابشن.

## 7) مرجع التصميم

### أنواع اللقطات (`SK.shots`)
```js
SK.brand({...});                       // من brand.json (new_project.py بيكتبه)
SK.preload({ logo:'assets/logos/x.svg', avatar:'assets/brand/avatar.jpg' });
SK.shots([
  { s:0,    e:2.06, kind:'split', bg:'beige' },                 // رسمة فوق + وجهه بكرت تحت وراسه طالع منه
  { s:2.06, e:3.86, kind:'full',  bg:'light', tr:'whip' },       // رسمة ملء الشاشة (+ capY لمكان الكابشن)
  { s:3.86, e:4.74, kind:'face',  zoom:1.14, tr:'flash' },      // وجهه ملء الشاشة (still:true = بدون زوم ولا قص)
  { s:15.0, e:16.4, kind:'full',  bg:'dark', tint:'#5A1410', tr:'glitch' } ]);
SK.panel(s, e, (lt) => { const t = s + lt; /* رسم */ });
```
- `bg`: اسم من الهوية أو hex. `nocap:true` بيشيل الكابشن (لما الرسمة فيها نفس الكلام). `capY` / `capSize` / `maxWords` لتعديل لقطة.
- **الأماكن:** split: الرسمة فوق y≈820، والكابشن بينحسب فوق راسه. full: الرسمة بالنص، والكابشن عند 1240. face: الكابشن تحت عند 1460.
- **منطقة آمنة (إنستغرام):** لا نص فوق y 150 ولا تحت 1620، ولا بين x 950–1080 لما y بين 1100 و1750.
- **split:** `SK.SPLIT.shift` (نزول الفيديو) و`headY` (أعلى راسه بالفيديو الأصلي) و`pop` (قديش الراس طالع) و`radius`. **افحصها بعينك**: الراس كامل والذقن فوق 1500. ⚠️ أغراض فاتحة جنبه (كنباية، حيط أبيض) أو حركة إيد كتير بتطلع كظل رمادي على الخلفية الفاتحة. وإذا ضل، خلّي هاللقطة على خلفية غامقة.
- **كابشن لقطات الوجه الكاملة:** `brand.faceCaption` (أصفر بإطار أسود رفيع). والكابشن بيتبني كلمة كلمة بدفعات بتمشي مع الكلام (بتنقطع عند الترقيم أو نفَس > 0.22 ث أو 4 كلمات، بدون كلمة يتيمة)، وبـ`SK.CAP.mode='sentence'` الجملة كاملة مرة وحدة.

### 7.1) الانتقالات (`tr:` على لقطة)
| tr | شكله | الصوت | إمتى |
|---|---|---|---|
| `flash` | فلاش أبيض/أصفر ثم برتقالي (0.16 ث) | كاميرا shutter | دخول على الوجه أو لحظة «كشف» |
| `card` | كرت بيكبر فوق القديمة | ووش ناعم | الافتراضي الهادي |
| `whip` | سحبة لجنب بضبابية | سوووش | دخول على رسمة full أو قائمة |
| `zoom` | القديمة بتنسحب والجديدة بتطلع من الزوم | ووش + ضربة | فكرة جديدة أو نتيجة |
| `glitch` | خلل وتقطيع ألوان | خلل رقمي | «مشكلة / ثغرة / خطأ» بس |
| `cut` | قطع مباشر | بدون | نادراً |

⛔ ما يتكرر نفس الانتقال مرتين ورا بعض، و`flash` و`glitch` للحظات إلها وزن، مش رشّ. الرسمة بتمشي مع الانتقال. صوت الانتقال بيجي من `trans_sfx.py` (بيتشغّل من `sfx.py`)، فلا تحط `soft` بـ`sfx.json` على نفس القطعات.

### 7.2) 🎬 الموشن الدلالي: الرسمة بتعيد تمثيل الكلام على توقيته
كل حركة مربوطة **بوقت كلمة** من `caps.json` مش بوقت تقريبي:
- `SK.wordT('عشرين')` ← `{s,e,i}` · `SK.span('سعر','الشهري')` ← الكلمات من كلمة لكلمة · `SK.typed(t, ws)` ← نص بينكتب حرف حرف وهو بيحكيه.

| بيحكي | الرسمة |
|---|---|
| «بحثت / جوجلت» | `SK.search(t,{inAt, query, searchAt, result:{at,title,url,icon,price:{to,prefix,suffix,at}}})`: شريط جوجل، كلامه بينكتب، ضغطة، نتيجة، والسعر بيعدّ على لفظ الرقم |
| «سألت ChatGPT / كلود» | `SK.chat(t,{inAt,title,icon,ask,sendAt,thinkAt,answer,answerAt})`: سؤاله بينكتب، إرسال، «بيكتب…»، الجواب كلمة كلمة |
| «جملة/أمر/تثبيت» | `SK.terminal(lt,x,y,w,h,[{t,c}],{cps,start,bg})` |
| «تابعني / فولو» بالآخر | `SK.follow(t,{inAt,tapAt,y})`: كرت بروفايله من brand.json (صورته، اسمه بينكتب، يوزره)، إصبع بيضغط Follow ← **Following ✓** + احتفال. **بدون عدد متابعين.** آخر لقطة `face` + `still:true` والكرت فوق راسه |
| رقم أو سعر | عدّاد بيوصل للرقم **على لفظ الرقم**. ⛔ ما بيبيّن الرقم قبل ما ينحكى |
| لوغو / كاراكتر | `SK.logo(lt,key,x,y,size,{walk:true})` · `SK.orbit` (بستايل الورق) |
| عنوان ضخم | `SK.bigGrad(lt,text,x,y,size)` |
| لقطة شاشة / فوكس | `SK.shot` · `SK.focus` · `SK.bars` · `SK.carousel` · `SK.pin` |

- **لما يحكي عن موشن/أنيميشن/تصميم نفسه، الرسمة لازم تكون احترافية** مش أشكال بسيطة: عدة نبضات على كلماته (شبكة تنرسم، حلقات HUD، كلمة بقناع، جزيئات، طابة على مسار بيزييه، تايملاين بمفاتيح، نجمة لامعة). مثال بـ`examples/`.
- ⚠️ بـshots.js لا تسمّي متغيرات `cl` / `lerp` / `ease` / `eio` / `back` / `rr` / `rgba` (موجودة بالمحرّك والصفحة بتوقف).
- أصوات الحركات بـ`sfx.json`: `pop` لما الشي بيطلع · `type` [بداية، مدة] للكتابة · `click` للضغط · `sub`/`shimmer` للرقم الكبير.

### 7.5) ملحقات ما عنده ياها؟ جيبها أو اعملها
- لقطة شاشة لموقع: `node $SRS/scripts/snap.js <work>/assets/x.png <url> 1280 800 4000`. ⚠️ مواقع بتحتاج تسجيل دخول أو بتحمّل ببطء بتطلع فاضية، فشوف الصورة قبل ما تستخدمها.
- ما زبط؟ اعمل صفحة HTML صغيرة بتشبه الشي (واجهة الأداة مع شعارها الحقيقي، موقع تجريبي، تقرير) وصوّرها بنفس الأداة. وقلّه إنها بديلة وإنه بيقدر يستبدلها بلقطة حقيقية.
