# أمثلة

ملفات `shots.js` حقيقية لريل 38 ثانية بالستايلين، عشان تشوف كيف بتنكتب اللقطات والرسومات.

- `paper-reel-shots.js`: ستايل الورق (ورق، شرائح، كرت وجه، تقسيمة، موشن احترافي، شات، بحث، تيرمنال، فولو)
- `split-reel-shots.js`: ستايل السبليت

**كيف تستفيد منها:** ما تنسخها كما هي. الأوقات مربوطة بكلام فيديو معيّن (مثلاً `W_('كرم')` بتدوّر على أول كلمة «كرم» بكلامه)، فاستخدمها كمرجع لأنماط: كيف بتربط رسمة بكلمة (`SK.wordT` / `SK.span`)، وكيف بتركّب موشن احترافي من عدة نبضات، وكيف بتحط تقسيمة ورسمة فوقها، وكيف بتخلص بكرت الفولو.

الأسهل: خلّي Claude يقراها وهو بيصمم لقطاتك (السكيل بيعرف مكانها).
